# Streaks: Simple Habit Tracker

A lightweight web app for building daily habits and keeping streaks alive.

## Features

- Add and delete habits
- Tap any of the last 7 days to mark a habit done or undo it
- Current streak shown for each habit
- Daily progress banner showing how many habits are done today
- Saved automatically in the browser (local storage)
- Responsive layout with light and dark themes, and keyboard-accessible controls

## How to use

1. Type a habit in the input box and press **Add**.
2. Tap the square for a day to mark it done. Tap again to undo.
3. Watch your streak grow. A streak counts consecutive completed days, and it stays alive through today until you finish the habit.

## Run it

The app is a single self-contained file, `habit-tracker.html`, with no build step and no dependencies. Open it in any modern browser.

## Limitations

- Data lives only in your browser, so it isn’t shared across devices
- Only the last 7 days are shown
- No reminders or accounts
